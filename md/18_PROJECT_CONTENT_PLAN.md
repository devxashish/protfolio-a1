## Presentation principle
No plain screenshot galleries. Each project moves through:
PROJECT → interactive demonstration → experience → explanation → proof →
result. Concretely: APK for apps, live URL for web projects, EXE tried
where applicable — always framed with enough narrative context that it
doesn't read as a dry technical listing.
