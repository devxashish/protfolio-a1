## Note on documentation structure
The master prompt recommends 22 numbered files. To keep the documentation
usable rather than fragmented, closely-related systems are grouped into
single files (e.g. physics + materials + motion + camera + lighting +
sound all live inside WORLD_DESIGN.md, since they all describe one
interaction language; performance + accessibility + responsive live
together since they're one "device behavior" concern). Every topic the
master prompt asked for is covered — just organized by concern rather than
split into one file per line-item. Numbering is kept from the requested
scheme where a file maps 1:1; grouped files are named for their combined
scope.
