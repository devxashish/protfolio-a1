# COLOR & TYPOGRAPHY SYSTEM

## Starting point
No forced personal color preference beyond a pull toward **black and
white** ("sabhi unhi se start hota hai" — everything starts from those) —
explicitly deferring the actual palette decision to color theory rather
than personal taste alone. The system is NOT locked to a single fixed
accent color — multiple colors are allowed, built on color theory and
semantic roles, as long as every color has a purpose and the palette never
reads as decorative/random ("multi-color does not mean rainbow").

## Proposed direction (for Phase 3 confirmation)
Black and white remain the structural base — inherently premium,
inherently "no gradients," and a natural mirror of the day/night duality
already core to the world. On top of that base, a small semantic color
system:

- **background / surface** — near-black and near-white (never pure
  #000/#FFF), shifting warmth/coolness between day and night modes.
- **primary text / structure** — derived from the black/white base at high
  contrast for legibility.
- **accent (interactive)** — a color-theory-driven hue used for
  interactive elements and the weight/symbolic motif; can pair with a
  second, harmonically related color (e.g. split-complementary) if the
  material and lighting systems call for it — but every additional color
  must justify its own existence, not just add variety.
- **muted / secondary** — a desaturated tone for supporting text and
  inactive states.

Day mode reads warmer and higher-contrast; night mode reads as accents
glowing against near-black rather than flat color blocks — reinforcing
the "room, lights on" reference. The exact hue(s) and harmony type
(analogous / complementary / split-complementary / triadic) are decided in
Phase 3, against the finalized material and lighting systems — not
guessed now.

## Typography
Confirmed: a **mix**, not one single typeface style. Proposed pairing
logic (Phase 3 to confirm):
- A confident, structural display face for headings / moments of impact
- A clean, quiet body face for reading — legibility first
- Optionally, a third "human" touch face (something with slightly more
  character) reserved for the About/story section specifically, to carry
  the personal narrative differently from the rest of the site.

No decorative/script fonts, no more than these 2–3 faces total.
